# BE-10 - 分销佣金与结算

## 1. 功能设计

- 邀请关系：首单绑定或注册绑定（产品规则）；树深度二级分润。
- 订单支付成功后计算佣金：`PENDING_PROTECT`（7 天维权期）→ `SETTLEABLE` → `T+7` 批量转可提现。
- 异常订单：冲正佣金流水。

## 2. 后端架构

- `CommissionService`；定时任务扫描 `SETTLEABLE` → 入账钱包或佣金子账户。
- 幂等：`order_id + beneficiary_user_id + level` 唯一。

## 3. 持久化要点

- `invite_relations`、`commission_entries`、`commission_settlement_batches`。
