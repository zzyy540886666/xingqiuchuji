# BE-05 - 合同与文书

## 1. 功能设计

- 支付成功后异步或同步生成 PDF/电子签；字段：甲乙方、商品、金额、租期、法律依据模板版本号。
- 上传 COS；生成 **短期签名 URL** 供小程序预览下载。

## 2. 后端架构

- `ContractService`；模板引擎（Freemarker/Thymeleaf）+ PDF（OpenPDF / iText 授权注意）。
- 若对接电子签：第三方回调更新 `contracts.sign_status`。

## 3. 持久化要点

- `contracts`：`order_id`、`template_version`、`cos_key`、`pdf_hash`、`created_at`。
