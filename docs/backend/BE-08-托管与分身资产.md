# BE-08 - 托管与分身资产

## 1. 功能设计

- 已购设备入库 `user_assets`；托管上架：可租时段、平台统一定价（来自配置表）。
- **冲突检测**：同一设备同一时段不可重复出租；与订单锁定字段联动。
- 收益：订单完成后分账到光年钱包或待结算池（与分销策略区分）。

## 2. 后端架构

- `TrusteeshipService`；下单前校验 `asset_lock`；Redis 锁 key：`asset:{id}:slot:{start-end}`。

## 3. 持久化要点

- `user_assets`、`trusteeship_slots`、`asset_revenue_ledger`。
