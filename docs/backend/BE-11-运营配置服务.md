# BE-11 - 运营配置服务

## 1. 功能设计

- 聚合返回：会员等级规则、权益文案、佣金展示、话题列表、星球卡 SKU、托管统一定价、QA 文案等。
- **版本化**：`config_version`；客户端上报本地版本，服务端返回 diff 或全量。

## 2. 后端架构

- `ConfigController`；Redis 缓存全量 JSON；后台变更时 bump version + pub/sub 失效（可选）。

## 3. 持久化要点

- `app_configs`：`key`、`value_json`、`version`、`effective_at`；或按域分表。
