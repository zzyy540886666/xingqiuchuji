# BE-04 - 支付与微信回调

## 1. 功能设计

- 根据订单创建 **微信支付预支付**（JSAPI）；返回 `timeStamp`、`nonceStr`、`package`、`signType`、`paySign`。
- **回调**：验签、解密、幂等更新订单与支付单；失败记录告警。
- 关单与退款（若一期含退款）：对接微信退款 API，独立退款单表。

## 2. 后端架构

- `PaymentController`（下单支付）、`WeChatPayNotifyController`（回调 URL，无 Bearer，验签）。
- `WeChatPayClient`；建议使用官方或社区维护的 V3 签名组件。
- 幂等键：`payment_orders.out_trade_no` 唯一；回调用 `transaction_id` 去重。

## 3. 持久化要点

- `payment_orders`：`order_id`、`amount`、`channel`、`status`、`wx_prepay_id`、`wx_transaction_id`。
