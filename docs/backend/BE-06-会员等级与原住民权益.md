# BE-06 - 会员等级、原住民与权益

## 1. 功能设计

- **原住民**：首次完成任意租赁/购买/软件付费后打标，终身有效。
- **等级**：L0～L3 规则由运营配置 + 消费累计快照计算；升级事件写 `membership_events`。
- **星球卡**：购买后延长或提升权益；微信支付成功回调内与会员服务同事务或可靠消息。

## 2. 后端架构

- `MembershipService`：`recalculate(userId)` 在订单支付成功后触发；定时全量校准（可选）。
- 权益核销：下单试算时读取 `user_benefits_snapshot` 或实时计算（注意性能）。

## 3. 持久化要点

- `user_membership`：`level`、`is_native`、`lifetime_spend`、`planet_card_expires_at`。
- `membership_benefit_grants`：免押次数等可扣减字段。
