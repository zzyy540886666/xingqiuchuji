# BE-02 - 商品目录、场景与搜索

## 1. 功能设计

- SKU 管理：租/买/软件类型、媒体、规格 JSON、价格策略（阶梯租、一口价、订阅）。
- 场景：运营配置场景与 SKU 关联；场景聚合接口返回分组卡片数据。
- 搜索：多条件组合查询；后续可接 ES，一期可 MySQL 索引 + 限制深度分页。

## 2. 后端架构

- `CatalogController`；`SkuService`、`SceneService`、`SearchService`。
- 读多写少：`@Cacheable` 或 Redis 缓存热门 SKU、场景配置（带版本号失效）。

## 3. 持久化要点

- `skus`、`sku_media`、`sku_prices`（或 JSON 列存阶梯，需可维护性权衡）。
- `scenes`、`scene_sku_rel`；搜索字段冗余索引。
