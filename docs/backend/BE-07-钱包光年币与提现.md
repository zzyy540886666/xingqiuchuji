# BE-07 - 钱包、光年币与提现

## 1. 功能设计

- 光年币：入账（活动、积分兑换、佣金可选策略）、出账（抵扣订单）、**流水不可删改**。
- 提现：校验余额、风控 → 创建提现单 → 调用企业付款到零钱 → 更新状态；失败可重试。

## 2. 后端架构

- `WalletService`：`credit`、`debit` 均写 `wallet_ledger` 再更新余额（或余额为派生视图）。
- 与支付同事务边界：订单支付成功不直接与钱包混在同一事务 unless 明确本地事务表；佣金入账可走异步。

## 3. 持久化要点

- `wallets`：`user_id`、`balance_minor`（分）。
- `wallet_ledger`：`type`、`amount_minor`、`ref_type`、`ref_id`、`balance_after`。
- `withdraw_requests`：`status`、`wx_batch_id`、失败原因。
