# FE-07 - 钱包与光年币

## 1. 功能设计

- **光年钱包**：余额、收支明细（订单、佣金、积分兑换、提现）。
- **提现**：输入金额 → 校验（最小额、手续费展示）→ 提交申请 → 展示状态（处理中/成功/失败原因）。
- **与社区联动**：积分兑换光年币或券的入口（若放在社区模块，此处仅钱包展示兑换记录）。

## 2. 前端架构

- `pages/wallet/index`、`pages/wallet/withdraw`；明细分页。
- 敏感操作二次确认；防重复点击（按钮 loading + 幂等由后端保证）。

## 3. 依赖接口

见 [api/API-04-会员钱包托管.md](../api/API-04-会员钱包托管.md) 钱包部分。

## 4. 验收要点

- 展示金额单位与精度与后端一致（分转元由统一 `formatMoney`）。
