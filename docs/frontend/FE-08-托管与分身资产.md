# FE-08 - 托管与分身资产

## 1. 功能设计

- **我的分身资产**：已购机器人列表；进入设备详情。
- **托管上架**：选择可租时段、确认平台统一定价（只读展示）；提交后展示审核/生效状态（若需运营审核则以后端状态为准）。
- **分身看板**：设备状态（空闲/已租/维护）、累计收益、租用记录列表。

## 2. 前端架构

- `pages/asset/list`、`pages/asset/device`、`pages/asset/trusteeship`。
- 日历或时间段选择组件与后端 **时区/营业时间规则** 对齐（统一用时间戳或 ISO 字符串约定）。

## 3. 依赖接口

见 [api/API-04-会员钱包托管.md](../api/API-04-会员钱包托管.md) 托管与资产部分。

## 4. 验收要点

- 与订单侧冲突时（设备已锁定）：错误提示来自后端 `code`，不写死文案。
