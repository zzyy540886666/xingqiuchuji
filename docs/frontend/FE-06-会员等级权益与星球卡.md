# FE-06 - 会员等级、权益与星球卡

## 1. 功能设计

- **展示**：Lv.0～Lv.3 名称、升级条件（消费额/年费）、权益列表（折扣、免押次数、分润层级等）。
- **权益看板**：剩余免押次数、维保次数、配件折扣、光年币余额入口、新物种体验提醒（运营配置项）。
- **付费升级**：星球卡 SKU 列表 → 微信支付 → 成功后刷新等级（轮询用户摘要或 WebSocket 可选）。

## 2. 前端架构

- `pages/member/index`、`pages/member/planet-card`；等级进度条数据来自 `GET /users/me/membership`。
- 权益项用 **配置驱动列表** 渲染，避免为每个权益写死独立组件（可扩展 `type` + 参数）。

## 3. 依赖接口

见 [api/API-04-会员钱包托管.md](../api/API-04-会员钱包托管.md) 会员部分。

## 4. 验收要点

- 等级「只升不降」的展示与后端快照一致；首单成为原住民后展示身份标识。
