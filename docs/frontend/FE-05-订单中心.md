# FE-05 - 订单中心

## 1. 功能设计

- **Tab**：租 / 买 / 软件；二级筛选：待付款、待履约、履约中、已完成、已取消。
- **租赁**：续租入口、取消规则与违约金提示（以后端规则为准）。
- **购买**：物流轨迹、确认收货、申请售后入口。
- **软件**：激活码/下载链接展示（敏感信息掩码 + 复制）；更新说明。

## 2. 前端架构

- `pages/order/list`、`pages/order/detail`；列表虚拟滚动（长列表时）。
- 状态标签与颜色映射 **由配置或枚举常量表** 与后端 `orderStatus` 对齐。

## 3. 依赖接口

见 [api/API-03-订单计价支付与合同.md](../api/API-03-订单计价支付与合同.md)。

## 4. 验收要点

- 订单详情所有金额字段与后端展示一致；操作按钮根据状态与后端 `allowedActions` 渲染（推荐）或前端枚举与后端同步维护。
