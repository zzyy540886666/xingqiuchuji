# FE-12 - 公共组件、埋点与规范

## 1. 功能设计

- **公共 UI**：空态、网络错误、加载骨架、Toast 规范；**图标统一极简 SVG**（不使用 emoji 作功能图标）。
- **埋点**：页面曝光、关键按钮、下单漏斗；失败与采样策略可配置。

## 2. 前端架构

| 项 | 建议 |
|----|------|
| 组件库 | 自研基础组件 + uni-ui 按需（团队定） |
| 样式 | 设计 Token：`colors.scss`、`spacing.scss` |
| 埋点 | `utils/track.ts` 调用 `POST /analytics/events`（批量/节流） |

## 3. 依赖接口

见 [api/API-06-分销与埋点.md](../api/API-06-分销与埋点.md) 埋点部分。
