# FE-13 - 报修工单与巡检小程序

> 来源：`docs/报修工单小程序系统功能清单.xlsx`

## 1. 页面与角色视图

### 1.1 普通用户视图

- 报修提交页：故障类型、地址、描述、图片上传、提交。
- 报修进度页：工单状态、维修员信息、处理记录、完成结果。
- 扫码报修页：扫描设备/场所二维码后自动带入点位信息。
- 我的报修页：工单列表、筛选、详情。
- 意见反馈页：文字+图片反馈。
- 个人中心页：个人信息、退出登录、我的报修入口。

### 1.2 维修员视图

- 工单大厅页：待接单、处理中、待验收、已完成、已驳回。
- 工单处理页：接单/拒单、上传维修图片、填写维修方案、耗材记录、故障原因。
- 巡检任务页：待巡检、巡检中、已完成、逾期。
- 扫码巡检页：扫码进入点位巡检表单，提交设备状态与隐患记录。

### 1.3 管理员视图

- 巡检计划页：设置周期（每日/每周/自定义）、绑定场所、指定维修员、设置时间要求。
- 任务监控页：巡检完成率、逾期点位、未巡检记录。
- 工单管控页：全域工单查询、手动指派、状态修改、加急。
- 简易看板页：故障概览、维修完成率。
- 消息提醒页：新工单、新巡检、逾期预警。

## 3. 状态模型

- `authStore`：当前角色（user/technician/admin）、token、权限集。
- `workorderStore`：工单列表、筛选条件、当前工单详情。
- `inspectionStore`：巡检任务列表、巡检表单草稿、提交状态。
- `dashboardStore`：管理员简易指标与预警信息。

## 4. 关键交互规范

- 报修、巡检提交必须有 loading / success / error 三态反馈。
- 上传图片失败需可重试且不丢失已填内容。
- 扫码失败或二维码无效时，提供手动选择点位兜底入口。
- 角色切换后重置与角色不匹配的缓存状态。

## 5. 依赖接口分组

- 认证：登录、退出、个人信息。
- 设备：二维码解析、点位查询。
- 工单：创建、查询、流转、日志。
- 巡检：计划、任务、记录、异常。
- 反馈：创建、处理状态查询。
- 消息：提醒列表、已读回执。
