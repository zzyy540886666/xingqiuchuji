# FE-10 - 即时通讯（IM）

## 1. 功能设计

- **私信**：会话列表、聊天页；支持文字、图片、表情（若 IM SDK 支持）。
- **圈子群聊**：从圈子进入群；成员与权限由 IM 与后端联合约束（踢人、禁言若需要）。

## 2. 前端架构

- 独立分包；初始化时向后端 `GET /im/token` 换厂商 Token；用户 ID 映射以后端为准。
- 与 **FE-09** 解耦：IM 仅负责会话 UI，社区 Feed 仍走 REST。

## 3. 依赖接口

见 [api/API-05-社区与消息.md](../api/API-05-社区与消息.md) IM 部分。

## 4. 验收要点

- Token 过期刷新策略；重连与未读数同步。
