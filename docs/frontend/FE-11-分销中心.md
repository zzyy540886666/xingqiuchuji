# FE-11 - 分销中心

## 1. 功能设计

- **推广工具**：生成带 `inviteCode` 的海报或复制链接（小程序路径 + query）。
- **团队看板**：一级/二级人数、简易树或列表（性能注意分页）。
- **佣金账单**：待结算、可提现、已提现；维权期与 T+7 说明文案来自配置。
- **提现**：与钱包联动或独立入口；异常冻结展示原因码。

## 2. 前端架构

- `pages/distribution/home`、`invite`、`team`、`commission`；图表可选轻量组件。

## 3. 依赖接口

见 [api/API-06-分销与埋点.md](../api/API-06-分销与埋点.md)。

## 4. 验收要点

- 分享路径带参在冷启动 `onLaunch` 解析写入归因 store，登录后绑定邀请关系（具体以后端接口为准）。
