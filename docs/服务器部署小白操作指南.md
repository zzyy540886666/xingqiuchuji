# 星球出机服务器部署小白操作指南（Ubuntu 22.04 + Docker）

> 适用对象：第一次买服务器、第一次部署网站/后端的小白。  
> 当前服务器：腾讯云轻量应用服务器，Ubuntu 22.04 LTS。  
> 当前公网 IP：`159.75.2.56`。如果你的控制台显示不是这个 IP，请把本文所有 `159.75.2.56` 替换成真实公网 IP。  
> 主域名：`xgear.life`。后续还要部署官网，所以本项目建议先使用子域名：`guanli.xgear.life`。  
> 部署方式：Docker / Docker Compose。  
>
> ⚠️ 重要：你的域名还没备案。中国大陆服务器正式对外提供网站、小程序接口、微信支付回调，通常需要先完成 ICP 备案。未备案前，可以先完成服务器安装、容器启动、IP 内部测试，但不要急着把正式业务接到微信支付和小程序线上环境。

## 1. 购买服务器后，腾讯云控制台先做什么

### 1.1 确认服务器信息

在腾讯云轻量应用服务器控制台确认：

```text
系统：Ubuntu 22.04 LTS
公网 IP：159.75.2.56
配置：2核4G / 70GB SSD / 6Mbps
登录方式：密码或 SSH 密钥
```

### 1.2 防火墙 / 安全组放行端口

在腾讯云控制台找到这台轻量应用服务器，进入：

```text
防火墙 / 安全组
```

至少放行：

| 端口 | 用途 | 是否放行 |
|---:|---|---|
| 22 | SSH 登录服务器 | 必须 |
| 80 | HTTP，申请 HTTPS 证书、备案前测试 | 必须 |
| 443 | HTTPS，后台/API/支付回调 | 必须 |

不要对公网开放：

| 端口 | 原因 |
|---:|---|
| 3306 | MySQL 不应公网暴露 |
| 6379 | Redis 不应公网暴露 |
| 8080 | 后端由 Nginx 转发，不直接暴露 |
| 8328 | 后端本机端口，不直接暴露 |
| 5137 | 后台前端本机端口，不直接暴露 |

## 3. 在服务器上安装基础软件

登录服务器后，逐条执行下面命令。

### 3.1 更新系统

```bash
sudo apt update
sudo apt upgrade -y
```

### 3.2 安装常用工具

```bash
sudo apt install -y ca-certificates curl gnupg lsb-release git unzip vim ufw nginx certbot python3-certbot-nginx
```

### 3.3 安装 Docker

```bash
curl -fsSL https://get.docker.com | sudo sh
```

### 3.4 允许当前用户使用 Docker

如果你是 `ubuntu` 用户：

```bash
sudo usermod -aG docker ubuntu
```

如果你是 `root` 用户，这一步可以跳过。

执行完后退出服务器再重新登录：

```bash
exit
```

然后在本地重新连接：

```powershell
ssh ubuntu@159.75.2.56
```

### 3.5 检查 Docker 是否安装成功

```bash
docker --version
docker compose version
```

能看到版本号就说明成功。

### 6.1 生成强密码的方法

在 Windows PowerShell 执行：

```powershell
[Convert]::ToBase64String((1..48 | ForEach-Object { Get-Random -Maximum 256 }))
```

执行一次复制结果，作为 `DB_PASSWORD`。再执行一次，作为 `REDIS_PASSWORD`。再执行一次，作为 `JWT_SECRET`。

### 6.2 微信支付证书放哪里

## 10. 配置服务器 Nginx

Docker 里的后台前端和后端只监听本机端口：

```text
后台前端：http://127.0.0.1:5137
后端 API：http://127.0.0.1:8328
```

我们用服务器上的 Nginx 把域名转进去。

### 10.1 创建 Nginx 配置

在服务器执行：

```bash
sudo tee /etc/nginx/sites-available/xingqiu << 'NGINX_EOF'
server {
    listen 80;
    server_name guanli.xgear.life;

    client_max_body_size 200m;

    location /api/ {
        proxy_pass http://127.0.0.1:8328;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 10s;
        proxy_read_timeout 60s;
    }

    location / {
        proxy_pass http://127.0.0.1:5137;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
NGINX_EOF
```

### 10.2 启用配置

```bash
sudo ln -sf /etc/nginx/sites-available/xingqiu /etc/nginx/sites-enabled/xingqiu
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx
```

### 10.3 测试 HTTP 访问

```bash
curl -I http://127.0.0.1
curl -I http://127.0.0.1/api/v1/admin/auth/me
```

第二条返回 `401`、`403` 或 `404` 都不一定是坏事，关键是不能连接失败、不能 Nginx 报 502。真正接口要以后按项目登录流程测试。

## 16. 常见问题排查

### 16.1 容器有没有启动

```bash
docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"
```

### 16.2 看后端日志

```bash
docker logs --tail=100 xq-backend
```

持续看日志：

```bash
docker logs -f xq-backend
```

### 16.3 看 Nginx 错误日志

```bash
sudo tail -n 100 /var/log/nginx/error.log
```

### 16.4 后台打不开

检查：

```bash
curl -I http://127.0.0.1:5137
curl -I http://127.0.0.1
sudo nginx -t
```

如果 `127.0.0.1:5137` 正常，但域名不正常，多半是 Nginx 或域名解析问题。

### 16.5 API 访问 502

检查后端是否正常：

```bash
docker ps | grep xq-backend
docker logs --tail=100 xq-backend
curl -I http://127.0.0.1:8328/api/v1/admin/auth/me
```

如果后端容器没起来，通常是 `.env`、数据库、Redis、微信/COS 配置导致。

### 16.6 MySQL 密码错了怎么办

如果是第一次部署，还没有真实数据，可以删除 Docker volume 重来：

```bash
cd /opt/xingqiu
docker compose -f docker-compose.prod.yml down -v
```

然后修正 `.env`，重新启动：

```bash
docker compose -f docker-compose.prod.yml --env-file .env up -d
```

⚠️ `down -v` 会删除数据库数据。正式上线后不要随便执行。

## 18. 你现在应该按什么顺序做

你现在是小白，建议严格按这个顺序，不要跳：

```text
第 1 步：腾讯云控制台开放 22、80、443
```
