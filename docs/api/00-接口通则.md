# 00 - 前后端接口通则

## 1. 基础约定

| 项 | 约定 |
|----|------|
| Base URL | `https://{env-host}/api/v1` |
| 协议 | HTTPS only |
| 格式 | `Content-Type: application/json; charset=utf-8` |
| 字段命名 | JSON **camelCase** |
| 时间 | **ISO-8601** 字符串，示例 `2026-05-05T12:30:00+08:00`；或统一 Unix 毫秒（二选一整站一致，推荐 ISO） |
| 金额 | **整数分**（minor unit），字段名后缀 `Amount`/`Price` 均为分，展示由前端格式化 |

## 2. 鉴权

- Header：`Authorization: Bearer <accessToken>`
- 登录、支付微信回调、健康检查等路径在网关/Security 配置 **匿名**。
- `accessToken` 过期返回 `401` + `code: UNAUTHORIZED`；客户端刷新或重新 `wx.login`。

## 3. 成功响应

统一包装（推荐，便于扩展 traceId）：

```json
{
  "success": true,
  "data": { },
  "traceId": "a1b2c3d4"
}
```

列表可直接 `data` 为数组，或：

```json
{
  "success": true,
  "data": {
    "items": [],
    "nextCursor": "opaque-string-or-null"
  },
  "traceId": "..."
}
```

## 4. 错误响应

```json
{
  "success": false,
  "error": {
    "code": "ORDER_NOT_PAYABLE",
    "message": "订单当前不可支付",
    "details": {}
  },
  "traceId": "a1b2c3d4"
}
```

- HTTP 状态：4xx 客户端 / 5xx 服务端；业务可预期错误可用 **200 + success false**（二选一整站一致，**推荐业务错误用 4xx/409** 与 HTTP 语义一致）。

## 5. 分页

- **游标分页**（推荐 Feed）：`cursor`、`limit`；返回 `nextCursor`。
- **页码分页**（管理类/订单）：`page`（从 1）、`pageSize`，返回 `total`、`items`。

## 6. 幂等与防重

- 支付、创建订单、提现：`Idempotency-Key: <UUID>` 请求头，服务端 Redis/DB 去重 **24h**。

## 7. 版本演进

- URL 版本 `/api/v1`；破坏性变更升 `v2` 或同版本下增字段不改语义。

## 8. 小程序域名

- 将 API 域名配置到微信公众平台 **request 合法域名**；COS 域名配置到 **downloadFile/uploadFile** 等按实际上传方式。
