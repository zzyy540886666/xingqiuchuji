## A类统一交付要求

1. 每项至少包含：后端单测/集成测试 + 前端关键交互验证。
2. 所有金额字段统一使用整数分，不接收浮点金额入库。
3. 涉及回调/事件任务必须具备幂等保障（唯一键、去重表或版本锁）。
4. 每项完成后在 PR 中附：改动摘要、测试结果、残余风险。
