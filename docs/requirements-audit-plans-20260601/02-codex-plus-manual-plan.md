# B类计划：Codex主导 + 人工协作（3项）

## T-P0-05 支付配置与联调验收

### Codex可交付

- 支持多环境支付配置读取（本地/测试/预发/生产）。
- 回调地址、签名校验、日志脱敏、幂等处理代码完善。
- 增加支付链路联调脚本与回调重放脚本（测试环境）。

### 必须人工完成

1. 在微信商户平台配置真实 `appid/mchid/apiKey/证书`。
2. 配置公网回调域名和 HTTPS 证书。
3. 安全侧确认回调白名单、证书轮换策略。
4. 用真机走通 `下单 -> 支付 -> 回调 -> 订单完成`。

### 验收点

- 覆盖 `TC-P0-03`、`TC-P0-04`。
- 证据要求：支付单号、回调日志、订单状态、联动记录同一单据可追溯。

## T-P1-03 星球卡接入微信支付

### Codex可交付

- 星球卡购买改为标准订单流，不再走钱包直接扣款。
- 支付成功后发放权益，并与会员体系联动。
- 增加失败回滚与重复回调幂等保护。

### 必须人工完成

1. 运营确认星球卡 SKU 与价格策略最终版本。
2. 财务确认星球卡收入科目和对账口径。
3. 真机执行成功/取消/失败 3 条支付路径验收。

### 验收点

- 覆盖 `TC-P1-04`。
- 证据要求：下单前无权益、成功后权益生效、失败后不生效。

## T-P2-02 IM 真正落地

### Codex可交付

- 接入 IM SDK 的服务端 token 下发、会话接口、消息持久化适配层。
- 前端接入会话列表、收发消息、未读数、重连处理。
- 增加降级策略：IM 不可用时提示与重试机制。

### 必须人工完成

1. 采购或开通融云/ZEGO 正式账号与应用。
2. 配置回调地址、敏感词/内容风控策略。
3. 真机双端网络切换（Wi-Fi/4G）做离线重连与未读一致性测试。

### 验收点

- 覆盖 `TC-P2-02`。
- 证据要求：单聊、群聊、图片消息、重连、未读计数五项均通过。

## B类推进节奏建议

1. 先完成 Codex 代码改造并在测试环境自测通过。
2. 再预约人工联调窗口（产品/运营/财务/运维/测试）。
3. 每项联调结束即沉淀“问题-修复-复测”闭环记录。
