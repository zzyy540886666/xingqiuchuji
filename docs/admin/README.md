# 后台管理网站文档索引

本目录定义面向平台管理员、运营、审核、财务及运维人员的 Web 后台规划。后台管理网站为独立 Web 工程，复用星球出机后端业务域和数据权威源，不替代小程序用户端。

## 契约声明

- 已有业务依据来自 `../frontend/`、`../backend/` 与 `../api/API-*.md`。
- 接口 Schema 的真源仍为 `../api/openapi/openapi.yaml`。该文件当前仅为健康检查占位快照，尚未覆盖后台管理接口。
- 本目录中的后台资源路径属于目标设计，必须在实施前进入 OpenAPI 并经过权限、审计和测试确认后方可供前端调用。
