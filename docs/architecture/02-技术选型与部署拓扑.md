# 02 - 技术选型与部署拓扑

## 1. 已定栈

| 层级 | 选型 | 版本建议 |
|------|------|----------|
| 小程序端 | UniApp | 以官方 LTS 与 Vue3 组合为准（团队锁定后写入 package.json） |
| 后端运行时 | OpenJDK | **17**（LTS） |
| 框架 | Spring Boot | **3.2+**（Jakarta EE 命名空间） |
| API 风格 | REST + JSON | 路径前缀 `/api/v1` |
| 持久化 | MySQL | **8.0**，InnoDB，utf8mb4 |
| 缓存 | Redis | **6.x/7.x**，会话、配置、分布式锁、限流 |
| 对象存储 | 腾讯云 COS | 与 CDN 联动 |
| 机审 | 腾讯云内容安全 | 文本、图片审核 API |
| 构建 | Maven 或 Gradle | 团队择一，多模块时可父 POM |
| API 契约 | **springdoc-openapi** + OpenAPI 3 | 运行时 `/v3/api-docs`，构建或发版时导出 YAML 提交到 `docs/api/openapi/` |

## 2. Spring Boot 工程结构建议（逻辑模块）

```
xingqiu-server/
├── xingqiu-app/          # Spring Boot 启动、全局配置、安全过滤器链
├── xingqiu-api/          # REST Controllers + DTO 校验（Bean Validation）
├── xingqiu-application/  # 应用服务：用例编排、事务边界
├── xingqiu-domain/       # 实体、值对象、领域服务、仓储接口
├── xingqiu-infrastructure/ # MyBatis/JPA、Redis、微信 SDK、COS、TMS、MQ
└── xingqiu-contract/     #（可选）OpenAPI 生成或共享 DTO 供前端类型生成
```

单体起步时可为单模块 `src/main/java` 下按包划分：`user`、`catalog`、`order`、`payment`…，与上述限界上下文一一对应，便于后续物理拆分。

## 3. 部署拓扑（验证期 → 成长期）

- **验证期**：CVM 2C4G 运行 Spring Boot JAR；云数据库 MySQL 2C4G HA；Redis 1G；COS + CDN；CLB 可选。
- **成长期**：多台应用 + CLB；MySQL 升配或读写分离；Redis 2G+；异步任务（分佣结算、合同生成）走 **Spring @Scheduled + DB 抢锁** 或 **MQ**（后续引入）。

## 4. 配置与环境

- `application-{dev,staging,prod}.yml` 外置敏感项（密钥用环境变量或腾讯云 SSM）。
- 微信、TMS、COS 使用 **子账号最小权限**。

## 5. 与文档的对应关系

- 功能级设计见 `docs/backend/BE-*.md`。
- **路径、请求/响应 Schema、枚举以 `docs/api/openapi/openapi.yaml`（由代码生成）为唯一真源**；`docs/api/00-接口通则.md` 为跨接口约定；`API-*.md` 可作模块说明，不得与 OpenAPI 冲突。

## 6. springdoc-openapi（落地要点）

- 依赖：`springdoc-openapi-starter-webmvc-ui`（与当前 Spring Boot 3 版本矩阵兼容的版本号由工程 BOM 锁定）。
- Controller / DTO 使用 `@Tag`、`@Operation`、`@Schema`、示例值等，保证生成文档可读。
- **生产环境**可关闭 Swagger UI，仅保留 JSON 文档端点或完全内网访问；**对外契约**以仓库内提交的 `openapi.yaml` 为准。
- 导出示例（本地）：`curl -s http://localhost:8080/v3/api-docs.yaml -o docs/api/openapi/openapi.yaml`（端口与路径按实际 `springdoc` 配置调整）。
