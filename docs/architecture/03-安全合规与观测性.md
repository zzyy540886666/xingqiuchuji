# 03 - 安全合规与观测性

## 1. 身份与鉴权

- 登录：小程序 `wx.login` → 后端换 `sessionToken`（或 JWT，**短有效期** + 刷新策略）。
- 所有 `/api/v1/**`（除登录、支付回调、健康检查）需携带 `Authorization: Bearer <token>`。
- **资源级鉴权**：订单、合同、钱包、帖子等接口必须校验 `resource.userId == currentUser`。

## 2. 资金与分销

- 支付回调：验签、幂等（`out_trade_no` / 微信单号唯一处理）。
- 钱包与佣金：**追加型流水表**，禁止原地改余额无流水。
- 提现：风控规则 + 企业付款接口；失败可重试队列与人工处理状态。

## 3. 内容与机审

- 腾讯云内容安全 Secret 仅服务端；前端直传 COS 使用 **STS 临时密钥**，作用域限制路径与前缀。
- 机审结果与人工复核状态写入业务表后再决定是否进入公域 Feed。

## 4. 通用安全（与 Skill `xingqiu-secure-by-default` 一致）

- 参数校验、防 SQL 注入（参数化）、输出编码防 XSS。
- 限流：登录、短信、下单、发帖、提现等敏感接口按 IP/用户维度限流。

## 5. 观测性

- **traceId**：网关或 Filter 生成，写入日志与错误响应。
- **指标**：JVM、HTTP 5xx、支付回调延迟、机审调用失败率。
- **审计**：管理类、提现、等级变更写审计表或不可篡改日志。
