# Rule 04 - 风险主题参考约束

本文件名仅为兼容历史引用保留。它不是 Codex 常驻启动规则，只在具体改动触及相应风险主题时按需读取。

## 主题约束

| 主题 | 需要核对的约束 |
| --- | --- |
| 接口与业务契约 | 影响字段、枚举、状态码或调用方时，以 `docs/api/openapi/openapi.yaml` 为真源 |
| 安全与鉴权 | 输入校验、资源权限、敏感信息、防注入和防 XSS |
| 资金与订单 | 整数分、幂等、状态审计与一致性 |
| 数据与外部集成 | 参数化访问、超时、错误处理、重试/降级按风险落实 |
| 部署与发布 | 参数、健康检查、观察指标和回滚 |
| UI 行为 | 合理的 loading/error/empty 状态和已有图标体系 |

## 使用方式

- 默认执行任务只读取实际触及的主题，不生成 Harness 文档。
- 触及高风险边界或被要求正式交付时，升级为受控交付并按 `AGENT-ROLE.md` 记录。
- 旧 `.trae/rules/*` 与历史 Changes 中的全量流程表述不构成 Codex 当前入口要求。
