# Rule 02 - 开发流程规范：阶段与门禁

## 固定阶段

1. 需求分析
2. 需求评审（最多 3 轮）
3. 任务拆分
4. 编码实现
5. 编码评审（最多 2 轮）
6. 单测编写
7. CI 验证
8. 部署准备
9. 部署执行
10. 最终确认与交付

## 每阶段三要素（必须具备）

- 触发条件
- Skill 加载
- 质量门禁

## 回退规则（精确路由，不从头重来）

- 需求不符 -> 回退到需求分析
- 编译错误 -> 回退到编码实现
- CI 失败且 `tests=0` -> 回退到单测编写
- CI 失败且有测试但未全通过 -> 回退到编码实现
- 部署参数错误 -> 回退到部署准备
- 验收失败 -> 回退到编码评审

## 人工确认点（5 个）

1. 需求待决议确认
2. 计划评审后确认
3. 编码评审后确认
4. 部署环境参数确认
5. 最终交付确认

## 升级条件

- 需求评审超过 3 轮 -> 升级人工决策
- 编码评审超过 2 轮 -> 升级人工决策
