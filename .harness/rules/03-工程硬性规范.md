# Rule 03 - 工程硬性规范

## 资金与订单

- 金额字段统一使用分（整数），禁止浮点金额
- 支付、回调、关单、结算流程必须幂等
- 订单状态变更必须可审计（流水、操作者、时间、上下文）

## 稳定性

- 所有外部调用必须设置超时
- 必须定义降级策略（缓存兜底、重试上限、错误码可识别）
- 禁止吞异常；必须记录可观测日志

## 安全

- 输入参数默认恶意：类型、长度、范围、枚举校验
- 禁止拼接 SQL，统一参数化
- 防 XSS：输入消毒与输出编码
- 敏感配置不得进仓库

## 契约一致性

- OpenAPI 为接口 Schema 真源
- 前后端字段、枚举、状态码必须一致
- 变更接口时同步更新文档与调用方

## UI 与交互

- 功能图标禁止 emoji，使用极简 SVG
- 页面必须具备 loading/error/empty 状态
