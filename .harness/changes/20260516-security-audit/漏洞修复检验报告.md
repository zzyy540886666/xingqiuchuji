#### VULN-005 | 全站无速率限制 | ✅ 已修复

| 检查项 | 修复前 | 修复后 |

**检验结论**: 基于 Redis 的滑动窗口限流，覆盖所有关键端点。超出限制返回 HTTP 429 + JSON 错误体（含 traceId）。✅

---

#### VULN-011 | 异常信息可能泄露 | ⚠️ 未修复

**当前状态**: `GlobalExceptionHandler.java` 未做修改。

**影响**: `BizException` 的 `message` 会回传给客户端。由于所有 BizException 均为业务代码手动抛出（非框架自动生成），message 处于开发者可控范围，当前风险较低。

**建议**: 如需修复，可在 `handleBizException` 中对 message 做一次白名单/模板化处理。
