- 基于 `docs/frontend/FE-01-13` 与 `docs/backend/BE-01-13` 映射后台模块，覆盖用户要求的商品信息、活动信息、运营管理、数据分析以及交易、审核、资金和报修等必要配套。
- 将活动一期约束为已有文档可支撑的场景专题和运营配置，未虚构优惠/秒杀等交易规则。
- 明确 `docs/api/openapi/openapi.yaml` 当前为占位契约；目标管理端路径仅作为待定设计，实施前必须写入契约。
- 文档中固定金额整数分、RBAC/数据范围、审计、幂等、traceId、第三方超时/重试/降级和 Docker 密钥外置要求。
- 对已有后台源码骨架中可能存在的越层访问和 DTO/审计缺口仅提出治理要求，本次不修改用户已有代码。
