## 2. 文档中定义的部署参数确认项

| 参数类别 | 实施前确认内容 |
| --- | --- |
| 镜像版本 | `admin-web`、`backend` 不可变镜像标签与回滚标签 |
| 网络入口 | HTTPS/TLS 终止位置、Nginx 反向代理路径 `/api/v1/admin/**` |
| 数据与缓存 | MySQL/Redis 连接、数据卷或托管实例、备份和恢复策略 |
| 密钥 | 管理认证、微信、COS、TMS 密钥通过 Secret 注入，生产无默认密码 |
| 契约 | 管理端 OpenAPI、角色/数据权限、审计字段已确认 |

## 3. 目标健康检查

| 服务 | 实施验证方式 |
| --- | --- |
| `admin-web`/Nginx | `/healthz` 与后台静态资源可访问，安全响应头有效 |
| Backend | Actuator liveness/readiness，管理登录/RBAC 与审计冒烟 |
| MySQL/Redis | 容器/托管健康状态、迁移版本、缓存/锁读写 |
| 业务链路 | 商品读取、配置草稿/预览、审计记录、关键看板查询 |

## 4. 目标回滚路径

| 失败类型 | 回滚路径 |
| --- | --- |
| Web 静态资源失败 | 回退 `admin-web` 镜像标签 |
| Backend 运行错误 | 回退兼容镜像并执行经批准的数据迁移回退/兼容策略 |
| 运营内容误发布 | 以旧配置生成新发布版本，触发缓存失效并保留审计 |
| 账务/结算异常 | 停止高风险动作并通过流水、审批和冲正修复，不直接改余额 |

## 5. 结论

- 本文件记录 Docker 方案的实施验证项和回滚路径，不构成已部署证明。
- 真实部署须待管理端契约、权限、实现、测试及仓库 CI 门禁全部满足后另行执行并更新验证记录。
