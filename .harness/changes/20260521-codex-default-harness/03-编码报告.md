# 03 编码报告

## 改动范围

1. 新增 `AGENTS.md`，作为 Codex 默认加载的 harness 入口。
2. 新增 `tools/harness/ci-gate.mjs`，串联类型检查与 Vitest，并生成机器可读 CI 结果。
3. 更新 `package.json`，追加 `test:unit` 与 `harness:ci` 脚本。
4. 更新 `.harness/README.md`，补充 Codex 默认入口与 CI 门禁说明。
5. 更新 `.gitignore`，忽略本地生成的 `.harness/ci/` 临时结果目录。

## 接口影响

无业务 API 变更。

## 数据影响

无数据库或业务数据变更。

## 风险影响

1. `package.json` 工作区已有未提交变更，本次仅在现有 scripts 上追加入口。
2. CI 门禁依赖本地 `node_modules` 与 Vitest JSON reporter；若依赖缺失会如实失败。

## 验证计划

1. 执行 `npm run harness:ci`。
2. 核对输出 `status=SUCCESS`、`tests>0`、`passed=total`。
3. 核对 `.harness/ci/latest.json` 字段完整。
