# 05 CI 结果

## 命令

```bash
npm run harness:ci
```

## 结果

```json
{
  "status": "SUCCESS",
  "tests": 24,
  "passed": 24,
  "total": 24,
  "failed": 0
}
```

## 门禁判定

1. `status=SUCCESS`：通过。
2. `tests>0`：通过，测试数量为 24。
3. `passed=total`：通过，24/24。

## 产物

1. 本地机器可读结果：`.harness/ci/latest.json`
2. Vitest JSON 报告：`.harness/ci/vitest-results.json`

说明：`.harness/ci/` 为本地生成目录，已加入 `.gitignore`；正式留痕以本文件为准。
