# 02 任务拆分清单

## 任务

1. 新增 `AGENTS.md`，作为 Codex 默认 harness 入口。
2. 新增 `tools/harness/ci-gate.mjs`，实现程序化 CI 三条件门禁。
3. 更新 `package.json`，追加 `test:unit` 与 `harness:ci` 脚本。
4. 更新 `.harness/README.md`，记录 Codex 接入方式。
5. 运行 `npm run harness:ci`，记录结果。

## 验证方式

1. 文件存在性检查。
2. `npm run harness:ci` 执行结果。
3. `.harness/ci/latest.json` 字段检查。

## 风险与阻塞

1. 如果既有代码类型检查失败，CI 门禁应返回 `FAILURE`。
2. 如果测试报告无法解析，CI 门禁应返回 `FAILURE`。
