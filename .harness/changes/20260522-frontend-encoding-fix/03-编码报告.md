# 编码报告

## 改动范围

- 修改 `index.html`：
  - 补齐 `<!doctype html>`、`html lang="zh-CN"`。
  - 增加 `<meta charset="UTF-8" />`，明确页面入口字符集。
  - 增加 viewport 与标题，保留原有 `#app` 挂载点和 `/src/main.ts` 入口脚本。
- 新增 `.editorconfig`：
  - 约束仓库文本文件默认 `charset = utf-8`。
  - 统一 LF 换行、末尾换行、尾随空格处理。
- 新增 `.gitattributes`：
  - 对前端常见文本文件声明 text 与 LF 换行，降低跨平台编辑导致编码/换行漂移的风险。

## 接口影响

无接口新增、删除或字段变更；不涉及 OpenAPI 契约。

## 数据影响

无数据库、缓存、订单、支付、金额字段变更。

## 分层与规则对齐

- 仅涉及前端入口与工程配置，不跨越业务分层。
- 未修改 API Client、Store、业务页面逻辑。
- 未引入浮点金额、SQL、外部调用、鉴权变更。

## 风险影响

- 若用户本地仍看到乱码，优先清理浏览器/微信开发者工具缓存并重新执行构建。
- `.gitattributes` 不会批量重写既有文件，只约束后续 Git 文本处理；本次未做全仓格式化。

## 验证计划

- 扫描 `index.html` 与 `src/` 常见乱码片段。
- 执行仓库级 `npm.cmd run harness:ci`。
- 执行 `npm.cmd run build:mp-weixin`。
- 扫描 `dist/build/mp-weixin` 常见乱码片段。
