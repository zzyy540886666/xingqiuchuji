## 设计稿转化说明

- `docs/前端代码` 为 React/Vite/shadcn 实现，本次未引入 React/Tailwind/shadcn，按 UniApp/Vue 页面能力重新实现。
- 搜索页：补齐历史搜索、搜索发现、隐藏发现、清空输入、结果列表与错误重试。
- 社区页：补齐分类 Tab、热门话题、Feed 图片网格、点赞/收藏/分享轻交互、浮动发帖入口。
- 商品详情页：补齐沉浸式商品图、租赁/购买/软件方案展示、时长选择、服务项、参数预览、说明折叠、底部操作栏。
- 订单确认页：由分步式表单改为设计稿确认页风格，保留订单试算、创建、支付与幂等键。
- 会员中心：补齐星空头部、等级进度、权益宫格、星球卡、权益说明与 FAQ。

## 接口影响

- 未新增或修改后端接口。
- 继续使用现有 `listSkus`、`searchCatalog`、`getSkuDetail`、`previewOrder`、`createOrder`、`requestPayment`、`getMembership`、`listFeed`。
- 订单创建仍使用 `Idempotency-Key`，未改变支付参数字段。
- 小程序 API 基址兜底由相对路径 `/api/v1` 调整为 `http://localhost:8080/api/v1`，仍优先读取 `VITE_API_BASE_URL`，避免微信端相对路径请求异常。

## 数据影响

- 不修改数据库结构。
- 金额展示继续使用 `formatMoney(整数分)`，未引入浮点金额作为业务存储或传输单位。
- 搜索发现、社区热门话题、会员卡兜底卡片为前端展示兜底，不写入业务数据。

## 风险影响

- OpenAPI 当前为占位文件，接口字段以现有 `src/services/types.ts` 为前端契约参照。
- 会员中心和社区部分设计元素在真实接口无数据时会展示空态/错误态；不会伪造成功数据。
- 后端未启动时，首页推荐和分类页会展示空态/错误重试，不再因 `errMsg` 缺失产生二次 TypeError。
- 微信自定义 tabBar 改为根级原生组件文件，避免 UniApp 仅拷贝 `.vue` 导致 DevTools 无法识别 custom-tab-bar。
- 构建出现 Sass legacy JS API deprecation warning，非本次新增错误，不阻断构建。
