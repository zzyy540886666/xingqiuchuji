## 评审意见

| 维度 | 问题 | 建议 | 优先级 |
|---|---|---|---|
| 需求一致性 | React 设计稿已转为 UniApp 页面，但首页与分类页原本已部分迁移，本轮只做必要补强 | 后续视觉验收时重点核对搜索、社区、详情、订单确认、会员中心五页 | P2 |
| 架构一致性 | 页面层未绕过 service/store，仍存在部分前端静态兜底数据 | 静态数据仅保留为发现词、话题和无配置兜底，不参与业务提交 | P2 |
| 契约一致性 | 未修改后端接口；订单、商品、会员字段沿用现有类型 | 后端 OpenAPI 更新后需再次对齐 `src/services/types.ts` | P2 |
| 安全性 | 搜索词、手机号、地址、备注均为用户输入 | 已做搜索 trim、手机号格式校验、备注 maxlength；后端仍需保留最终校验 | P2 |
| 数据一致性 | 订单确认页改为直接确认支付流程，存在重复提交风险 | 保留 `ensureIdempotencyKey` 与 `clearIdempotencyKey`，不改变幂等链路 | P1 |
| 可观测性 | 页面重构可能遗漏关键路径埋点 | 已保留搜索、社区分类、商品下单、订单试算/提交/支付等 `trackClick` 或 `trackPageView` | P2 |
| 可测试性 | UI 视觉变化难以由现有单测完全覆盖 | 已执行 type-check、mp-weixin build、unit test、harness CI；真机视觉验收登记为未验证项 | P2 |
