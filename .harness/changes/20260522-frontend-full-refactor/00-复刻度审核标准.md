# 复刻度审核标准

## 页面级

- 目标页面以 `docs/前端代码/src/app/routes.tsx` 为准：
  - `Home` -> `src/pages/home/index.vue`
  - `Category` -> `src/pages/catalog/index.vue`
  - `Community` -> `src/pages/community/index.vue`
  - `Profile` -> `src/pages/mine/index.vue`
  - `Search` -> `src/pages/search/index.vue`
  - `ProductDetail` -> `src/pages/product/detail.vue`
  - `OrderConfirm` -> `src/package-order/pages/order/create.vue`
  - `MembershipCenter` -> `src/package-member/pages/member/index.vue`
- 每页需对照首屏结构、区块顺序、顶部导航/状态栏、底部固定栏、横向滚动区、浮动按钮。

## 组件级

- 商品卡、搜索条、底部 TabBar、空态、加载骨架、错误重试、媒体轮播、价格块、固定操作栏必须与目标交互角色一致。
- 技术栈允许从 React/Tailwind 翻译为 UniApp/Vue/SCSS，但组件职责不能丢失。
- 功能图标使用项目 SVG 或小程序可用 SVG/图片，禁止 emoji 功能图标。

## 视觉样式

- 核心 token：
  - 主色：`#0A4BFE`
  - 背景：`#F5F6F8` / `#F5F6FA`
  - 价格红：`#F53F3F`
  - 成功绿：`#00B578`
- 需要重点复核：
  - 首页三卡、场景应用横滑、推荐三列商品。
  - 分类顶部三段 Tab、左侧分组筛选、右侧排序筛选。
  - 社区 Feed 卡片、话题条、浮动发布按钮。
  - 我的页蓝色渐变头图、会员卡、资产/功能宫格。
  - 会员中心深蓝星空头部、等级成长、星球卡、权益说明。

## 路由交互

- 所有跳转必须映射到 `src/pages.json` 已注册页面。
- 对设计稿存在但当前小程序未实现的 H5 路由，必须转为现有分包页面或 `uni.showToast({ title: '功能开发中' })` 降级。
- 不允许存在点击后进入未注册页面的死链。

## API 与状态

- 页面必须通过 `src/services` 与 `src/stores` 接入真实接口，不用设计稿 mock 数据替代核心链路。
- API 契约以 `docs/api/API-*.md` 和 `00-接口通则.md` 为当前可用真源；`openapi.yaml` 业务 schema 缺失需记录为风险。
- 金额保持整数分输入，展示由 `formatMoney` 统一格式化。
- 数据页必须覆盖 loading/error/empty：
  - 首页推荐
  - 分类列表
  - 搜索结果
  - 社区 Feed
  - 商品详情
  - 订单预览/创建/支付
  - 我的/会员中心
