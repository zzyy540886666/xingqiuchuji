# 任务拆分清单

| 任务 | 影响层 | 负责人/Agent | 依赖 | 验证方式 | 风险 |
| --- | --- | --- | --- | --- | --- |
| 梳理 `docs/前端代码` 目标页面与资源 | Page/Component/Style | 设计迁移探索 Agent | 目标设计代码 | 目录与页面映射报告 | React/Tailwind 到 UniApp 存在语义差异 |
| 梳理 `docs/api` 与服务层差距 | API Client/Types/Store | API 契约探索 Agent | API 文档 | 路径字段枚举差距报告 | OpenAPI 内容不足，需参考 API-*.md |
| 建立复刻度审核标准 | Review | 复刻度审核 Agent | 目标设计代码、当前 src | 审核清单与偏差清单 | 视觉细节不可完全程序化 |
| 重构首页/分类/搜索/社区 | Page/Component/Style/API | UI Worker | 设计映射、服务层 | 页面源码、构建、复刻审核 | 页面较多，样式容易偏差 |
| 重构商品详情/订单确认/我的/会员 | Page/Store/API | Commerce Worker | API 契约、设计映射 | 下单链路、构建、复刻审核 | 涉及幂等、支付、金额展示 |
| 校准服务层与类型 | API Client/Types/Store | Service Worker | docs/api | 单测、类型检查 | 字段名与后端不一致会导致联调失败 |
| 补齐缺失静态图标与无效路由降级 | Static/Route | 主 Agent | 页面引用清单 | 构建与静态扫描 | 不应引入 emoji |
| 运行 CI 与小程序构建 | Test/CI | 主 Agent | 代码完成 | `harness:ci`、`build:mp-weixin` | 既有改动可能暴露非本次问题 |
| 记录编码报告、复刻度审核、CI、部署验证 | Harness | 主 Agent + 审核 Agent | 实现与验证结果 | changes 文件 | 必须保留版本递增 |
