# 需求分析文档

## 需求来源

用户要求重构前端全部代码，严格将 `docs/前端代码` 中设计好的 React/Tailwind 前端翻译为当前 UniApp/Vue 小程序代码，并遵循 `docs/api`，确保可以和后端接口连接。同时要求多 Agent 并行协作，并指定必须有独立 Agent 负责审核验证和复刻度。

## 目标用户

- 微信小程序普通用户：浏览首页、分类、搜索、详情、下单、会员、社区、我的等核心页面。
- 测试与验收人员：按 `docs/前端代码` 对照页面复刻度，按 `docs/api` 对照接口可连通性。
- 后端联调人员：通过统一 API Client、字段枚举和错误处理对齐后端 REST JSON API。

## 业务场景

前端需要从静态 React 设计稿转译到 UniApp 小程序实现，既保留视觉与交互，又接入后端真实接口。核心场景包括：

- 首页机器人租赁/购买/软件入口、场景应用、推荐商品。
- 分类页筛选、排序、商品列表。
- 搜索页历史搜索、搜索发现、结果列表。
- 商品详情、租赁/购买模式、购物车、订单确认和微信支付。
- 社区 Feed、关注、点赞、收藏、发布入口。
- 我的、会员中心、钱包、资产、分销等入口。

## 范围边界

### 目标范围

- 以 `docs/前端代码/src/app/pages/*.tsx` 为设计真源，翻译为 `src/**/*.vue`。
- 以 `docs/api` 为契约真源，校准 `src/services/*`、`src/services/types.ts`、Store 与页面调用。
- 保留 UniApp 小程序运行约束，不直接引入 React、Tailwind、lucide-react 或浏览器 DOM API。
- 页面必须保留 loading/error/empty 状态，避免纯静态假数据替代接口联调。
- 独立审核 Agent 产出复刻度审核标准，并在实现后复核偏差。

### 非目标范围

- 不重构后端 Java 代码。
- 不变更 OpenAPI 或 API 文档字段语义。
- 不引入微信云开发。
- 不执行真实生产部署。

## 依赖系统

- 目标设计代码：`docs/前端代码`
- API 契约：`docs/api/00-接口通则.md`、`docs/api/API-*.md`、`docs/api/openapi/openapi.yaml`
- 当前小程序源码：`src/`
- 构建与测试：`npm.cmd run harness:ci`、`npm.cmd run build:mp-weixin`

## 契约触点

- Base URL：`/api/v1`
- Header：`Authorization: Bearer <accessToken>`
- 幂等：创建订单等写操作使用 `Idempotency-Key`
- 统一响应：`{ success, data, traceId }` / `{ success:false, error, traceId }`
- 金额：整数分，前端仅负责格式化展示
- 商品：`/catalog/skus`、`/catalog/skus/{skuId}`、`/catalog/search`、`/catalog/scenes/{sceneId}/bundles`
- 订单：`/orders/preview`、`/orders`、`/orders/{orderId}/payments/wechat-jsapi`
- 用户/会员/钱包/社区/分销/资产/报修：按 `docs/api/API-04` 至 `API-07`

## 多 Agent 分工

- 设计迁移探索 Agent：梳理 `docs/前端代码` 页面、组件、文案、资源和迁移顺序。
- API 契约探索 Agent：梳理 `docs/api` 与当前 `src/services` 的差距。
- 复刻度审核 Agent：建立并执行页面/组件/样式/文案/路由/API/状态的复刻度审核清单，只读验证，不写代码。
- 实现 Worker：按 disjoint write set 分页面与服务层实现，避免相互覆盖。

## 验证标准

- 设计复刻度：核心页面结构、中文文案、视觉层级、交互入口与 `docs/前端代码` 对齐。
- 契约一致性：服务层路径、字段、枚举、金额单位、鉴权与幂等符合 `docs/api`。
- 程序化门禁：`harness:ci` 输出 `status=SUCCESS`、`tests>0`、`passed=total`。
- 构建门禁：`build:mp-weixin` 成功。
- 静态检查：无 emoji 功能图标、无明显乱码、无缺失静态资源引用、无明显无效页面跳转。

## 风险点

- `docs/前端代码` 是 React/Tailwind/H5 设计代码，需翻译为 UniApp/Vue，无法逐行复制。
- `docs/api/openapi/openapi.yaml` 当前内容较少，详细契约主要分散在 `docs/api/API-*.md`。
- 当前工作树已有大量未提交改动，本次必须只围绕前端重构工作推进，不回滚既有改动。
- 目标设计中存在 H5 路由，当前小程序部分目标页面未建，需通过现有分包页面或“功能开发中”降级避免跳转不存在页面。

## 回退前提

- 编译失败：回退到编码实现阶段，按失败文件修正。
- CI tests=0：回退到单测编写阶段。
- 复刻度审核发现 P1/P0 偏差：回退到对应页面实现。
- API 字段或路径不一致：回退服务层与调用点。
