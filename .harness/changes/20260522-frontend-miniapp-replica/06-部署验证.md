# 06-部署验证

## 部署状态

本轮未上传微信小程序审核。已生成微信开发者工具可导入产物。

## 本地运行参数

依赖安装后可在 `frontend` 目录执行：

```bash
npm install
npm run dev:mp-weixin
```

构建微信小程序：

```bash
npm run build:mp-weixin
```

当前可直接导入微信开发者工具的目录：

```text
D:\Pro\星球出机小程序 - 副本\frontend\dist\build\mp-weixin
```

当前开发模式产物目录也已刷新：

```text
D:\Pro\星球出机小程序 - 副本\frontend\dist\dev\mp-weixin
```

## 健康检查

- 仓库级门禁：`npm run harness:ci`
- 当前结果：`SUCCESS`，`tests=5`，`passed=5`，`total=5`
- UniApp 构建：`npm run build:mp-weixin`，结果 `DONE Build complete.`
- WXSS 复核：已移除微信开发者工具不接受的 `*` 选择器。
- 图片复核：已将原 Unsplash 图片替换为本地 `static/images` 资源，降低开发者工具运行超时风险。

## 上线前检查

- 微信公众平台配置 request 合法域名：后端 API 域名，路径前缀 `/api/v1`。
- 如后续使用 COS 或 CDN 图片，微信公众平台需配置 downloadFile 合法域名。
- `frontend/src/manifest.json` 中 `mp-weixin.appid` 替换为真实小程序 appid。
- OpenAPI 补齐业务接口后，替换 `frontend/src/data/mock.ts` 静态数据。

## 回滚路径

- 若小程序构建失败：回退到编码实现阶段，优先修复 `frontend` 页面或依赖配置。
- 若真机图片不可用：先替换为 COS 资源或配置合法域名，不回退业务页面结构。
- 若真实 API 字段不一致：回退到需求分析与 OpenAPI 对齐阶段，再调整 mapper。
