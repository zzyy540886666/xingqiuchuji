# 02-任务拆分清单

| 序号 | 任务 | 模块/分层 | 验证方式 | 依赖 | 风险 |
| --- | --- | --- | --- | --- | --- |
| 1 | 创建 `frontend` UniApp 工程骨架 | frontend/Page | 检查 `package.json`、`src/main.ts`、`src/App.vue`、`src/pages.json` | 无 | 构建依赖需后续安装 |
| 2 | 翻译公共样式、状态栏、底部导航、商品卡 | frontend/Component | 静态检查组件存在并被页面引用 | 原型 Layout | 图标体系需避免 emoji |
| 3 | 翻译首页、分类、搜索 | frontend/Page | 页面文件存在，关键文案和路由入口可查 | 原型 Home/Category/Search | 原 Tailwind 样式需重写 |
| 4 | 翻译商品详情与确认订单 | frontend/Page | 页面文件存在，金额展示通过整数分工具 | 原型 ProductDetail/OrderConfirm | 真实下单接口未定义 |
| 5 | 翻译社区、我的、会员中心 | frontend/Page | 页面文件存在，互动状态本地可切换 | 原型 Community/Profile/MembershipCenter | 原型部分装饰需用 CSS 重建 |
| 6 | 增加请求封装与金额格式化 | frontend/API Client + Mapper | 单测覆盖 `/api/v1`、Bearer、金额格式化 | API 通则 | 业务接口仍为占位 |
| 7 | 接入仓库 CI 门禁 | tools/tests | `npm run harness:ci` 生成 latest.json | Node.js | 不能依赖未安装第三方包 |
| 8 | 写入编码报告、评审记录、CI 结果、部署验证 | harness/changes | 文件存在且内容可复核 | 变更完成 | 不得删除历史版本 |

## 分层核对

- Page：`frontend/src/pages/**`
- Component：`frontend/src/components/**`
- Store/State：页面内局部状态和静态数据模块，暂不引入全局状态库。
- API Client：`frontend/src/utils/request.ts`
- Mapper：`frontend/src/utils/format.ts` 与页面展示数据格式化。

## 阻塞项

- 未发现业务 OpenAPI 详细路径，真实数据接入不在本轮完成。
- 当前环境未安装 UniApp 依赖，程序化门禁采用静态工程校验与 Node 单测，真实小程序构建需依赖安装后执行。
