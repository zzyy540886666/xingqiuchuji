- 建议：在依赖安装完成后执行 `cd frontend && npm run build:mp-weixin`，并把结果追加到 CI/部署验证记录。
- 优先级：P1
- 状态：已处理，`npm run build:mp-weixin` 构建成功。

### 2. 图片外链真机加载存在域名限制

- 问题：页面沿用原型 Unsplash 图片，微信真机需要合法域名配置，开发者工具可能出现 `timeout`。
- 建议：上线前将图片迁移到 COS 或微信合法下载域名；当前开发产物先使用本地静态资源。
- 优先级：P2
- 状态：已处理，本轮已替换为本地静态资源。

### 3. 业务接口未接入真实数据

- 问题：OpenAPI 当前只有 `/meta/ping`，商品、订单、会员、社区接口不能以代码静态数据代替契约。
- 建议：后续补齐 OpenAPI 后，新增 API Client 方法和 mapper，并为每个接口补测试。
- 优先级：P1
- 状态：已按非目标范围登记。
