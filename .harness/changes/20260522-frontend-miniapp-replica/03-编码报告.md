## 契约对齐

- API 前缀固定为 `/api/v1`。
- 请求头保留 `Authorization: Bearer <accessToken>`。
- 幂等请求保留 `Idempotency-Key`。
- 请求超时设置为 `10000ms`。
- 金额展示工具 `formatAmount` / `formatPriceCompact` 强制校验整数分，拒绝非整数金额。
- OpenAPI 当前仅含 `/meta/ping` 占位，业务页面暂使用静态 mock 数据，未私造后端字段结论。
