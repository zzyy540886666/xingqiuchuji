# 我的页真实数据与微信登录交付记录

## 目标与范围

- 将“我的”页的用户、会员、钱包、资产、托管收益、分销、报修、消息入口全部接入后端接口与数据库关系，不再使用页面硬编码或本机留言数据。
- 增加微信小程序一键登录入口，登录后由后端 code2session 换取 openid 并签发 JWT。
- 补齐用户中心相关数据库字段、外键、唯一约束、金额检查和开发种子数据。
- 同步 OpenAPI 契约中本次新增/调整的用户中心接口。

## 风险触点与关键决策

- 鉴权：`/distribution/**` 不再匿名放行，个人资产、钱包、消息、报修、分销均依赖 JWT 当前用户。
- 微信集成：未配置微信登录、微信支付或商家转账参数时明确失败，不生成伪 openid、伪支付单或伪提现。
- 金额：钱包、订单、会员卡、托管收益、佣金仍以整数分字段传输和存储。
- 种子数据：允许作为数据库初始化数据存在；前端不直接读取种子文件，所有页面通过后端 API 和关系表查询。

## 实际改动

- 前端：`pages/profile/index.vue` 增加微信一键登录，所有个人中心指标改为调用 `users/me`、会员、钱包、资产收益、通知、分销接口；消息页改为数据库通知列表；资产、钱包、分销、会员、报修页面字段与后端 DTO 对齐。
- 后端：新增当前用户摘要接口，补会员卡列表、分销团队成员、报修附件上传、资产收益归属校验；微信登录移除本地伪 openid；微信支付和提现改为真实签名链路与配置缺失显式失败。
- 数据库：`backend/sql/init.sql` 对核心用户中心表补充外键、唯一约束、金额/区间检查；`seed-data.sql` 重写为与实体字段一致的用户中心关系种子。
- 契约：`docs/api/openapi/openapi.yaml` 增加微信登录、当前用户、会员、钱包、资产、分销、通知相关路径。
- 门禁：更新 `tools/harness/run-tests.mjs`，不再要求保留“星球玩家小白”旧硬编码假用户名，改为检查微信登录入口。

## 验证证据与结果

- `mvn -q -DskipTests compile`：通过。
- `npm.cmd run build:mp-weixin`：通过；Uni/Sass 输出既有 legacy JS API deprecation 警告。
- `npm.cmd run harness:ci`：`status=SUCCESS`，`tests=5`，`passed=5`，`total=5`。

## 未验证事项与回退

- 未使用真实微信小程序 `WX_APP_ID/WX_APP_SECRET`、微信支付商户证书和商家转账配置做线上联调；需在真实环境配置后完成微信端到端验收。
- 回退方式：回退本次前后端接口、数据库脚本、OpenAPI 和 harness 测试改动；如果数据库已初始化过，需按约束/字段变更编写反向迁移或重建开发库。
