## 五、读取原则

1. **阶段触发加载**：需求分析/编码实现/编码评审阶段，按上方表格"必须查阅的阶段"列加载对应文档
2. **按需补充加载**：遇到不明确字段/枚举/状态码时，追加查阅对应的 API/后端文档
3. **沉淀到 changes**：查阅后关键发现写入 `changes/<需求ID>/01-需求分析文档.md` 的风险/约束章节
4. **不主动加载**：会话初始时不加载 Wiki 层内容，只在上述触发条件下加载
