# Expert Reviewer Skill

## 评审范围

- 需求评审（最多 3 轮）
- 编码评审（最多 2 轮）

## 输出格式（每条必填）

- 问题：描述风险或偏差
- 建议：给出可执行修复建议
- 优先级：P0/P1/P2

## 评审维度

1. 需求一致性（是否偏离需求）
2. 架构一致性（是否违反规则与分层）
3. 契约一致性（字段、枚举、状态码）
4. 安全性（鉴权、校验、注入、越权）
5. 数据一致性（事务、幂等、缓存一致性）
6. 可观测性（日志、traceId、失败定位）
7. 可测试性（是否可被程序化验证）

## 轮次与升级

- 需求评审超过 3 轮 -> 升级人工决策
- 编码评审超过 2 轮 -> 升级人工决策
